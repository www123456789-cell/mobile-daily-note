# 剪贴板摘要

手机端 Obsidian 插件：一键把剪贴板上的文字和图片整理成一篇带日期的 AI 总结笔记。

## 它能做什么

你复制一段文字（有时候也复制了图片），点一下按钮，插件会：

1. 读取剪贴板上的文字，能读到的图片也一起读出来
2. 交给「AI 笔记总结」生成一份中文要点总结
3. 新建一篇笔记，标题就是当前时间，例如 `# 2026-09-15 21-32`
4. 图片自动保存并内嵌进笔记，原文默认保留在末尾方便核对
5. 自动打开这篇笔记；读不到图片时，光标会停在「图片」节，你长按粘贴即可

生成的笔记长这样：

```markdown
---
date: 2026-09-15
tags:
  - 剪贴板
---

# 2026-09-15 21-32

## 🤖 AI 总结
…AI 总结正文…

## 🖼️ 图片
![[剪贴板/附件/2026-09-15 21-32-05.png]]

## 📄 原文
…你复制进来的原文…
```

## 启动方式（不用命令面板）

三种任选，都只需要点一下：

- **手机工具栏**：设置 → 移动端 → 管理工具栏 → 添加「剪贴板生成 AI 总结笔记」
- **侧边栏图标**：左侧抽屉里的剪贴板图标
- **手机桌面图标**：把 `obsidian://clipboard` 做成 iOS「快捷指令」的「打开 URL」动作，或 Android 上用 Shortcut Maker 之类指向它

## 依赖

- 需要 [ai-note-summary](https://github.com/www123456789-cell/ai-note-summary)（保持原版即可，本插件只调用它现成的方法，不改动它），并在它里面填好 API Key

## 设置

| 设置项 | 默认值 | 说明 |
| --- | --- | --- |
| 笔记保存文件夹 | `剪贴板` | 笔记放哪里 |
| 笔记命名格式 | `YYYY-MM-DD HH-mm` | 同名自动加序号 |
| AI 插件 ID | `ai-note-summary` | 一般不用改 |
| 总结提示词 | （见默认值） | 决定 AI 怎么整理 |
| 保留原文 | 开 | 在末尾保留剪贴板原文 |
| 图片文件夹 | `剪贴板/附件` | 剪贴板图片存这里 |

## 说明

- 剪贴板图片能否自动读到，取决于手机系统是否允许；读不到时插件会留好粘贴位置，不影响使用
- AI 没配置或调用失败时，笔记照常生成并保留原文，不会丢内容
