# 每日笔记助手（mobile-daily-note）

一个为**手机端**设计的 Obsidian 每日笔记插件：一键生成今天的笔记，自动写好日期、星期和当天课程，留好放照片的位置，排好待办清单；还能把录音转写笔记的 AI 分析直接写进「今日课程」板块。

## 功能

- **一键开今日笔记**：工具栏/命令面板点一下，`日记/2026-09-14.md` 就建好了（文件夹和文件名格式可配）
- **自动日期与星期**：`# 2026-09-14 周一`，不受系统语言影响
- **当日课程自动列出**：在设置里填一周课表（`周一: 高等数学, 大学英语`），当天有课就自动列出来
- **待添加图片**：预生成 `- [ ] 📷` 占位，手机键盘上方的 📎 一拍即插
- **代办计划**：可配默认项，另有「加一条待办」命令，随时插到板块末尾
- **AI 分析写进课程栏**：与 `ai-note-summary` 联动（见下）
- **只补不删**：笔记已存在时只追加缺失板块，绝不覆盖你写的内容

## 安装

**方式一：手动**
把 `mobile-daily-note` 整个文件夹放进 `<你的库>/.obsidian/plugins/`，然后在 设置 → 第三方插件 里启用。
目录层级必须是 `plugins/mobile-daily-note/manifest.json`，不要多套一层。

**方式二：BRAT**
装 [BRAT](https://github.com/TfTHacker/obsidian42-brat)，Add Beta plugin 填 `www123456789-cell/mobile-daily-note`。

## 与「AI 笔记总结」联动

把录音转写笔记的 AI 分析直接写进每日笔记的「今日课程」板块，效果：

```markdown
## 📚 今日课程
- [ ] 高等数学
<!-- ans:begin source="转写/录音 高等数学 2026-09-14.md" hash="adba997e" -->
### 🤖 高等数学 · AI 分析
> 来源：[[转写/录音 高等数学 2026-09-14|录音 高等数学 2026-09-14]]　由 AI 生成，请核对后使用

本讲核心是极限的 ε-δ 定义……
<!-- ans:end source="转写/录音 高等数学 2026-09-14.md" -->
```

- **不需要改动** [ai-note-summary](https://github.com/www123456789-cell/ai-note-summary)：本插件只是调用它实例上现成的 `callAI` 方法和你配好的设置；如果它自己提供了 `api`，则优先用 `api`
- **省钱**：每篇转写笔记的内容会算一个 hash 写进标记，内容没变就不重复调 API，也不会产生重复段落；内容改了才重新分析，且是**原地替换**
- **触发方式**：打开今日笔记时自动扫、命令「AI 分析今日转写笔记并写入课程栏」、命令「把当前笔记的 AI 分析写入今日课程栏」

## 命令

| 命令 | 用途 |
| --- | --- |
| 打开或创建今日笔记 | 主入口，建议加到移动端工具栏 |
| 今日笔记：加一条待办 | 随时记一件事，插到「代办计划」末尾 |
| 今日笔记：在"待添加图片"加一个占位 | 照片位置不够时补一个 |
| 光标处插入图片占位 | 任意笔记光标处插入 `- [ ] 📷` |
| AI 分析今日转写笔记并写入课程栏 | 扫描今天的转写笔记并写入课程栏 |
| 把当前笔记的 AI 分析写入今日课程栏 | 只处理当前打开的这一篇 |

## 主要设置

| 设置项 | 说明 |
| --- | --- |
| 笔记存放文件夹 | 默认 `日记`，不存在会自动创建 |
| 文件名格式 | 默认 `YYYY-MM-DD` |
| 一周课程表 | `周一: 高等数学, 大学英语`，每行一天 |
| 待办默认项 | 每天的高频待办，每行一条 |
| 图片占位数量 / 提示语 | 「待添加图片」板块的预生成内容 |
| 自定义模板文件 | 库内路径，支持 `{{date}} {{weekday}} {{courses}} {{todos}} {{images}}` |
| AI 插件 ID | 默认 `ai-note-summary` |
| 转写笔记文件夹 / 关键词 | 决定扫哪些笔记当作转写笔记 |
| 只分析今天的转写笔记 | 按文件名日期或修改时间判断 |
| 打开今日笔记时自动分析 | 内容是缓存命中的话不会调 API |

## 开发说明

单个 `main.js`，纯 JavaScript（CommonJS），无构建步骤、无第三方依赖，改完直接重载插件即可。`isDesktopOnly: false`，手机端可用。
